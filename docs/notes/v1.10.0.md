**🇬🇧 HA Taskbar parle anglais** (Windows)
- Toute l'interface est traduite : barre, cartes, palette, réglages, widgets, notifications. La langue **suit celle de Windows** : français si Windows est en français, anglais sinon. Pour la forcer : **Réglages → Connexion → Langue**.
- Le programme d'installation et la version portable sont aussi en anglais sur un Windows anglais.
- Le README existe maintenant en anglais : [README.en.md](https://github.com/bbtoff/home-assistant-taskbar/blob/main/README.en.md). La version Mac reste en français pour l'instant.

**🧪 Exemples de configuration** dans le README
- **Couleurs selon la valeur** prêtes à copier : température, CO₂, humidité, consommation, production solaire, piles, prix de l'électricité, qualité de l'air…
- **Recettes** pour les options d'un élément : groupe, raccourci clavier, clic du milieu, badge, plage horaire, action au clic…
- Voir la section [Exemples de configuration](https://github.com/bbtoff/home-assistant-taskbar#-exemples-de-configuration).

**🖼️ Icônes et logos dans les widgets** (Windows et Mac)
- Chaque widget peut afficher une **icône** à côté de son titre : celle du capteur (par défaut), aucune, ou une icône au choix.
- Ou ton **propre logo** : une image (PNG ou GIF sous Windows ; PNG, JPEG, HEIC… sur Mac), copiée dans le dossier des réglages.
- Windows : **clic droit sur un widget → Icône** ou **Choisir un logo…** ; Mac : **Réglages → Widgets**, ou clic droit sur le widget.

**🍎 macOS**
- **80 icônes de plus** pour les éléments et les widgets : luminaires, ventilateurs, purificateur, électroménager, salle de bain, meubles, multimédia, sécurité, recharge de voiture, batterie domestique, jardin, animaux…
- **Mini-graphique** de la barre des menus : il suit maintenant la couleur de la barre (claire ou sombre) exactement comme les icônes.

Si tu as la 1.8.2 ou plus récente sur Mac, l'application te propose cette mise à jour d'elle-même. Sous Windows, la mise à jour automatique la propose aussi.

**Quel fichier choisir ?**
- Windows : `HATaskbar-Setup-1.10.0.exe` (**recommandé**, avec mises à jour automatiques) ou `HATaskbar-Portable-1.10.0.zip` (sans installation).
- Mac : dans le Terminal, `curl -fsSL https://raw.githubusercontent.com/bbtoff/home-assistant-taskbar/main/macos/install.sh | bash` (**recommandé**), ou `HATaskbar-macOS-1.10.0.dmg`.

HA Taskbar n'est pas signé numériquement : au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » (**Informations complémentaires** → **Exécuter quand même**), et avec le `.dmg`, macOS demande **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**.
