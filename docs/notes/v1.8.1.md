**🔒 Jeton d'accès chiffré**
- Le jeton n'est plus écrit en clair dans `config.json` : il est chiffré avec la **protection des données de Windows** (DPAPI). Seul ton compte Windows, sur ce PC, peut le relire.
- Rien à faire : ta configuration actuelle est chiffrée automatiquement au premier lancement.
- Version portable copiée sur un autre PC (ou un autre compte Windows) : le jeton ne peut pas y être déchiffré, HA Taskbar te demande simplement de le coller à nouveau.
- Pour sauvegarder ou changer de PC, utilise **Réglages → Confort → Sauvegarde → Exporter…** : le fichier ne contient jamais le jeton.

**🍎 HA Taskbar pour macOS**
- Tes capteurs et boutons Home Assistant dans la **barre des menus** du Mac (macOS 13 ou plus, Apple Silicon et Intel), apparus avec la 1.8.0.
- Sur Mac, le jeton est rangé dans le **trousseau macOS**.
- **Appui long plus fiable** pour ouvrir la carte d'une lumière, d'une prise…
- Nouveau réglage **Clic sur un élément : Ouvrir la carte** (Réglages → Général) : le clic ouvre la carte, et ⌥-clic fait l'action.
- Corrections : curseurs de la carte sans graduations parasites, dates lisibles sur l'historique.

**Quel fichier choisir ?**
- Windows : `HATaskbar-Setup-1.8.1.exe` (**recommandé**, avec mises à jour automatiques) ou `HATaskbar-Portable-1.8.1.zip` (sans installation).
- Mac : `HATaskbar-macOS-1.8.1.dmg`, à ouvrir puis glisser HA Taskbar dans Applications.

HA Taskbar n'est pas signé numériquement : au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » (**Informations complémentaires** → **Exécuter quand même**), et macOS demande un clic droit → **Ouvrir**.
